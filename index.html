Privacy and safety

Never enter bank passwords, OTPs, UPI PINs, card security codes or sensitive account details. Finorra is not connected to banks and does not move money. Keep a backup before changing devices.

Local data stays in this browser. Cloud copies are stored in your own Supabase project and protected by account-level database policies.

About this version

Finorra uses local browser storage and automatic Supabase synchronisation when signed in and online. It is an educational personal-finance organiser, not a bank, financial adviser or audited financial service. It does not connect to banks or move money.
