Privacy and safety

Data is stored in this browser's local storage, not encrypted cloud storage. Never enter bank passwords, OTPs, UPI PINs, card security codes or sensitive account details. Use sample data while testing.

Clearing browser data may erase your entries. Download backups regularly.

Delete all local data

About this version

This is a single-file local prototype. User accounts, multi-device sync, secure cloud backup, bank connections, notifications and production-grade security require a separately developed backend and security review. This app does not connect to banks or move money.
